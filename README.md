# Quantum Simulation of H₂O₂ O–O Bond Dissociation with VQE

A reproducible quantum-computational chemistry benchmark of homolytic H₂O₂ O–O bond dissociation using a CAS(2,2) active space and the Variational Quantum Eigensolver (VQE).

## Research question

How do active-space reduction, fermion-to-qubit mapping, variational ansatz choice, optimization behavior, finite sampling, and circuit resources affect a small quantum-chemistry calculation along the H₂O₂ O–O dissociation coordinate?

## Computational workflow

```text
H₂O₂ geometry grid
        ↓
RHF / CAS(2,2) / full-space FCI references
        ↓
Qiskit Nature active-space Hamiltonian
        ↓
JW / BK / parity mappings
        ↓
2-qubit parity reduction
        ↓
VQE: UCCSD and EfficientSU2
        ↓
PES + error decomposition + convergence analysis
        ↓
shot-noise model + circuit resources
        ↓
CSV / JSON tables + publication-quality figures
```

## Current study status

The repository contains the **actual ideal-state VQE study run by the author**, including the dissociation PES and COBYLA convergence trajectories. The canonical notebook is the original research notebook in `notebooks/H2O2_VQE_Bond_Dissociation.ipynb`; the modular Python pipeline in `run_study.py` regenerates the same study outputs from the pinned environment.

The current analysis separates two scientifically different sources of discrepancy:

- **VQE error:** `|E_VQE - E_CAS(2,2)|`
- **active-space/model-space error:** `|E_CAS(2,2) - E_FCI|`

This prevents the difference between VQE and full-space FCI from being incorrectly attributed entirely to the quantum optimizer.

## Methods

- Molecule: H₂O₂
- Basis: STO-3G
- Charge: 0
- Spin: 0 (closed-shell singlet in the source workflow)
- Active space: CAS(2 electrons, 2 spatial orbitals)
- O–O scan: 1.00, 1.20, 1.45, 1.80, 2.20, 2.60, 3.00 Å
- Classical references: RHF, CAS(2,2), full-space FCI
- Qubit mappings: Jordan–Wigner, Bravyi–Kitaev, standard parity, 2-qubit reduced parity
- VQE ansätze: UCCSD and EfficientSU2
- Primary optimizer: COBYLA
- Chemical-accuracy threshold: 1.6 mHa

## One-command study execution

After creating the pinned environment:

```bash
conda env create -f environment.yml
conda activate h2o2-vqe
python -m pytest -q
python run_study.py
```

`run_study.py` is the canonical end-to-end pipeline. It generates the seven-point geometry grid, classical reference energies, Hamiltonian validation, mapping comparison, equilibrium VQE benchmark, UCCSD potential-energy surface, convergence trajectories, resource estimates, CSV/JSON outputs, and figures.

The numerical result files are generated programmatically rather than manually populated. This keeps regenerated results authoritative and prevents copied benchmark values from being mistaken for a fresh computation.

## Important methodological note

The finite-shot section should be interpreted carefully: it performs an exact-estimator VQE and then applies a Gaussian post-processing perturbation with σ ∝ 1/√Nshots. It is therefore a **shot-noise statistical model**, not a full finite-shot optimization using sampled Pauli measurements.

Likewise, this repository does **not** claim quantum advantage or a hardware demonstration. STO-3G and CAS(2,2) are deliberately small methodological choices. Full-space FCI is an exact reference within the STO-3G basis, while CAS(2,2) is the direct target of the reduced VQE calculation.

## Interpretation

The current study is best understood as a resource-aware methodological benchmark. The central scientific distinction is:

```text
VQE → CAS(2,2) agreement
        ≠
CAS(2,2) → full-FCI agreement
```

A successful VQE can accurately solve the chosen reduced Hamiltonian while the active-space approximation remains the dominant source of chemical error. The convergence study at equilibrium and at a stretched O–O distance further examines how the optimization trajectory changes along bond dissociation.

See [`docs/RESULTS_INTERPRETATION.md`](docs/RESULTS_INTERPRETATION.md) for the detailed interpretation framework.

## Next experimental layer

The ideal-state study is the baseline. Planned extensions are:

1. actual finite-shot Pauli expectation estimation;
2. shot-count sensitivity;
3. Aer gate/readout noise;
4. optimizer comparison under matched evaluation budgets;
5. circuit transpilation and hardware-resource analysis;
6. larger active spaces and basis-set sensitivity.

The existing Gaussian shot-noise model should not be presented as an actual finite-shot hardware experiment.
