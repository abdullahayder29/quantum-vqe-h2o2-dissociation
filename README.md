# Quantum Simulation of H₂O₂ O–O Bond Dissociation with VQE

A reproducible quantum-computational chemistry benchmark of homolytic H₂O₂ O–O bond dissociation using a CAS(2,2) active space and the Variational Quantum Eigensolver (VQE).

## Research question

How do active-space reduction, fermion-to-qubit mapping, variational ansatz choice, optimization behavior, finite sampling, and circuit resources affect a small quantum-chemistry calculation along the H₂O₂ O–O dissociation coordinate?

## Computational workflow

```text
H₂O₂ geometry grid
        ↓
RHF / CAS(2,2) / full-space FCI references
        ↓
Qiskit Nature active-space Hamiltonian
        ↓
JW / BK / parity mappings
        ↓
2-qubit parity reduction
        ↓
VQE: UCCSD and EfficientSU2
        ↓
PES + VQE error + active-space error
        ↓
COBYLA convergence analysis
        ↓
circuit-resource analysis
        ↓
CSV / JSON tables + figures
```

## Current results

The current completed run provides two important layers of validation:

- the reduced 2-qubit UCCSD VQE closely tracks the exact CAS(2,2) reference along the sampled O–O dissociation coordinate;
- the CAS(2,2) reference remains distinct from full-space FCI, separating **VQE/optimization error** from **active-space/model error**.

The convergence analysis also compares the equilibrium geometry near 1.45 Å with the stretched 3.00 Å geometry, allowing the optimization landscape to be examined rather than reporting only final energies.

See [`docs/RESULTS_INTERPRETATION.md`](docs/RESULTS_INTERPRETATION.md) for the scientific interpretation and limitations.

## Methods

- Molecule: H₂O₂
- Basis: STO-3G
- Charge: 0
- Spin: 0 (closed-shell singlet in the source workflow)
- Active space: CAS(2 electrons, 2 spatial orbitals)
- O–O scan: 1.00, 1.20, 1.45, 1.80, 2.20, 2.60, 3.00 Å
- Classical references: RHF, CAS(2,2), full-space FCI
- Qubit mappings: Jordan–Wigner, Bravyi–Kitaev, standard parity, 2-qubit reduced parity
- VQE ansätze: UCCSD and EfficientSU2
- Primary optimizer: COBYLA
- Chemical-accuracy threshold: 1.6 mHa

## One-command study execution

After creating the pinned environment:

```bash
conda env create -f environment.yml
conda activate h2o2-vqe
python -m pytest -q
python run_study.py
```

`run_study.py` is the canonical end-to-end pipeline. It generates the seven-point geometry grid, classical reference energies, Hamiltonian validation, mapping comparison, equilibrium VQE benchmark, UCCSD potential-energy surface, convergence trajectories, active-space error analysis, resource estimates, CSV/JSON outputs, and figures. The pipeline does not hard-code benchmark energies.

## Important methodological notes

The notebook describes its stack as “Qiskit 1.x”, but its recorded installation and validation output show Qiskit 2.5.2. The repository preserves the recorded computational environment rather than silently rewriting the source study.

The finite-shot section currently uses an exact-estimator VQE followed by a Gaussian perturbation with σ ∝ 1/√Nshots. It is therefore a **shot-noise statistical model**, not a full finite-shot optimization using sampled Pauli measurements. The ideal VQE results remain the primary benchmark.

## Scientific interpretation

This is a **small-system methodological benchmark**. It does not claim quantum advantage, does not represent a hardware demonstration, and does not imply that CAS(2,2)/STO-3G is chemically converged for H₂O₂. Full-space FCI values are references within the STO-3G basis; CAS(2,2) is the direct target of the active-space VQE calculations.

The key analytical distinction is:

```text
VQE error       = |VQE - CAS(2,2)|
Active-space    = |CAS(2,2) - full-space FCI|
model error
```

Keeping these errors separate prevents an inaccurate VQE result from being confused with a limitation of the chosen active-space model.
