# Results interpretation

This document explains how the current H₂O₂ benchmark should be interpreted scientifically. The numerical values are generated by the pipeline; this document deliberately avoids hard-coding values so that regenerated results remain authoritative.

## 1. Potential-energy surface

The main PES compares:

- RHF
- exact CAS(2,2)
- UCCSD VQE in the reduced 2-qubit parity representation
- full-space FCI in STO-3G

The current run shows the reduced UCCSD VQE curve closely tracking the exact CAS(2,2) reference over the scanned O–O distances. This establishes that the variational calculation is accurately solving the chosen active-space problem.

The CAS(2,2) and full-space FCI curves remain separated. This distinction is scientifically important: an accurate VQE solution of a reduced Hamiltonian does not imply that the reduced Hamiltonian is chemically complete. The CAS–FCI difference should therefore be treated as a **model-space error**, while the VQE–CAS difference is an **algorithmic/optimization error**.

## 2. Error decomposition

The pipeline now reports two independent quantities:

\[
\Delta E_{\mathrm{VQE}} = |E_{\mathrm{VQE}}-E_{\mathrm{CAS(2,2)}}|
\]

and

\[
\Delta E_{\mathrm{active}} = |E_{\mathrm{CAS(2,2)}}-E_{\mathrm{FCI}}|.
\]

This decomposition prevents the common mistake of attributing the entire VQE-to-FCI discrepancy to the quantum algorithm.

The VQE error is plotted against the 1.6 mHa chemical-accuracy threshold. The active-space error is plotted separately along the same dissociation coordinate.

## 3. Optimizer convergence

The pipeline records COBYLA energy evaluations at two deliberately contrasting geometries:

- the equilibrium point near 1.45 Å;
- the most stretched point at 3.00 Å.

The purpose is not merely to show that the optimizer converges, but to examine whether the optimization landscape changes as the O–O bond is stretched. The stretched calculation can require a different optimization trajectory even when the final VQE energy remains close to the CAS reference.

## 4. Scientific conclusions supported by this benchmark

The current benchmark supports the following hierarchy of conclusions:

1. **Active-space VQE feasibility:** a 2-qubit UCCSD calculation can reproduce the exact CAS(2,2) target for this small H₂O₂ problem.
2. **Model-space limitation:** the CAS(2,2) approximation is not equivalent to full-space FCI, particularly along the dissociation coordinate.
3. **Optimization behavior matters:** convergence trajectories change between equilibrium and stretched geometries.
4. **Resource reduction matters:** parity/symmetry reduction substantially lowers the qubit requirement and should be evaluated together with Hamiltonian and circuit complexity.

These conclusions do **not** establish quantum advantage and do not imply chemical convergence with respect to basis set or active-space size.

## 6. Next experimental layer

The current ideal-state results should remain the baseline. The next scientifically distinct experiments are:

1. actual finite-shot Pauli expectation estimation;
2. shot-count sensitivity;
3. Aer gate/readout noise;
4. optimizer comparison under matched evaluation budgets;
5. circuit transpilation and hardware-resource analysis;
6. larger active spaces and basis-set sensitivity.

The existing Gaussian shot-noise model should not be presented as an actual finite-shot hardware experiment.
