# Results

This directory stores machine-readable outputs generated by the computational workflow.

## Organization

```text
results/
├── classical/
├── vqe/
├── noise/
└── resource_estimates/
```

## Required provenance

Each result file should record, directly or through an associated metadata file:

- date/time of generation;
- software environment or environment lock;
- molecule and basis set;
- geometry / O–O distance;
- active-space definition;
- mapper and symmetry-reduction settings;
- ansatz;
- optimizer and convergence settings;
- simulator/backend;
- number of shots, when applicable;
- random seed, when applicable;
- source script or notebook cell.

## Reproducibility rule

Results must be generated programmatically. Do not manually edit numerical results. If a computational change modifies a result, preserve the previous version in Git history and document the methodological change.
