# Research Notebook

The main computational workflow is based on the uploaded H₂O₂ VQE benchmark notebook.

## Workflow covered

1. Environment and Qiskit/PySCF validation
2. C₂-symmetric H₂O₂ geometry generation
3. Classical RHF and FCI reference calculations
4. Second-quantized Hamiltonian construction
5. Jordan–Wigner and parity mappings
6. VQE implementation
7. Potential-energy-surface benchmarking
8. Shot-noise and quantum-resource analysis

The original notebook is intended to be kept as the primary reproducibility artifact for this project.
